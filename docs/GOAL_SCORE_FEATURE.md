# Goal Pace 機能試作

最終更新：2026-08-23  
状態：本体未統合・テストページで検討中

## 目的

練習（スコア）の開始前に目標点を設定し、入力中に以下を確認できるようにする。

- 現在点から目標点までの進行
- 残り矢数で目標へ到達するために必要な1本平均
- 現在の得点進行が目標ペースより前か後ろか
- 目標達成済み、または残り矢数では到達できない状態

## 表示方針

- 「あと○点」という文章は主表示にしない。
- 残り点は、横方向のシークバーにある未到達部分として可視化する。
- 必要平均は数値に加え、的面上の境界線として表示する。
- 得点の矢印と目標ペースの白線を同じシークバーへ表示する。
- 色は通常を緑、達成を金、目標未到達予測を橙とする。失敗を強調する全面的な赤表示は使わない。

## モチベーション表示

飛翔ルート上に以下の4要素を統合する。

- 次エンドゲート：次の3本または6本で目標ペースを維持する合計点と、回復・上積みの目安を表示する。
- ゴーストペース：自己ベスト、直近の同種目、直近5回平均のいずれかを半透明の矢として比較表示する。
- 着地予測ゾーン：直近3エンド以内の平均から最終得点の予測範囲を表示し、残り矢数が減るほど帯を収束させる。
- FINISH STRONG：当初目標が数学的に到達困難になった場合、当初目標を残したまま、狙える着地点への分岐ルートを表示する。

エンド確定時だけ現在位置と次ゲートを短く強調する。`prefers-reduced-motion` が有効な端末ではアニメーションを停止する。

## 計算

```text
残り矢数 = 総矢数 - 入力済み矢数
不足点 = max(0, 目標点 - 現在点)
必要平均 = 不足点 / 残り矢数
目標ペース点 = 目標点 × 入力済み矢数 / 総矢数
次ゲート累計点 = 目標点 × 次エンド終了時矢数 / 総矢数
着地中心予測 = 現在点 + 直近最大3エンドの1本平均 × 残り矢数
```

- 必要平均が種目の1本満点を超えた場合は「到達困難」とする。
- 三つ目的の重複射は、ペナルティ適用後の有効点を現在点へ使用する。
- Xは10点として計算する。

## 本体統合時の保存項目

- `goalScore`：当該セッションの目標点
- `goalScoreUpdatedAt`：練習中に目標を変更した場合の更新日時

目標点は下書き自動保存と本保存の両方へ含める。目標点の変更だけでセッションを終了させない。

## テストページ

`outputs/goal-score-test.html`

本体の保存データには触れない独立ページ。種目、目標点、スコア入力、取り消し、12本デモ入力を備える。

テストページのゴースト比較値は表示検証用の仮データ。本体統合時は保存済みの同種目履歴から自己ベスト・直近・直近5回平均を計算する。
